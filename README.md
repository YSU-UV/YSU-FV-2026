# YSU ROULETTE — 연성대학교 룰렛

연성대학교 축제 부스용 오프라인 3칸 슬롯머신입니다.

## 실행 방법
1. ZIP 압축을 풀어 `seven-club-3slot` 폴더를 준비합니다.
2. 폴더 안의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. USB 대형 Enter 키나 일반 키보드 Enter를 누르면 슬롯이 작동합니다.
4. 우측 상단 ⚙ 설정에서 상품명, 잔여 수량, BGM, 효과음, 회전 시간을 설정할 수 있습니다.
5. 설정의 `1등`~`4등` 소리 미리듣기는 상품 수량을 차감하지 않습니다.

온라인 서비스나 설치는 필요 없습니다. 단, `index.html`, `assets/`, `sounds/`, `y2k-arcade-loop.ogg`의 상대 경로를 유지해주세요.

## 심볼 (총 6종)
연성대학교 로고, 도형 아이콘, 포치타, 펭귄, 커비, 토끼.

## 결과 유형 / 가능한 배열 수
- **4등: 전부 다름** — 3칸 모두 다른 심볼: 6 × 5 × 4 = **120개**
- **3등: 2개 일치** — 2칸만 같은 심볼: 6 × 5 × 3 = **90개**
- **2등: 3개 일치** — 연성대학교 로고 외 심볼 3개 일치: **5개**
- **1등: YSU 잭팟** — 연성대학교 로고 3개 일치: **1개**
- 총 **216개** 배열.

등급은 수량 비율에 따라 뽑으며, 등급 내 가능한 배열은 각각 같은 확률로 나타납니다. 예를 들어 1등 남은 5회, 전체 100회면 1등 당첨 확률은 5%입니다. 해당 등급이 뽑히면 남은 수량은 즉시 1회 차감됩니다.

## 보존 및 운영 주의
- 상품 수량, 상품 이름, 음량, 회전 시간은 로컬 브라우저에 저장됩니다. 자동 일일 초기화는 없습니다.
- 기존 폴더를 같은 경로에 **덮어쓸 경우**, 같은 브라우저/저장소에서 기존의 남은 수량과 사용자 지정 상품 이름을 계속 사용합니다.
- 이전 버전의 수정되지 않은 기본 상품명 `777 특별 상품`만 자동으로 `YSU 특별 상품`으로 변경됩니다.
- 두 개 이상의 브라우저 탭이나 컴퓨터에서 동시에 운영하지 않는 것을 권장합니다.
- 브라우저 데이터를 삭제하면 저장된 수량이 사라질 수 있습니다.
